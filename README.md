# 🧮 Simple Calculator

A simple Android calculator application developed using Kotlin and XML in Android Studio. The application allows users to perform basic arithmetic operations and view their previous calculations through a history feature.

---

## 📌 Project Overview

The Simple Calculator is an Android application developed to perform basic mathematical calculations easily.

The application provides a simple interface where users can enter numbers, perform arithmetic operations, view results, and access their calculation history.

---

## ✨ Key Features

### 🔢 Basic Arithmetic Operations

The application supports basic mathematical operations:

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)

### 🗑️ Delete Operation

- DEL button to remove the last entered character.

### 🟰 Calculation Result

- Displays the entered numbers and mathematical expressions.
- Calculates and displays the final result using the equals (=) button.

### 📜 Calculation History

- Provides a separate History screen.
- Allows users to view previous calculations.

## 🔄 Application Workflow

1. Open the Simple Calculator application.
2. Enter numbers using the calculator buttons.
3. Select the required arithmetic operation.
4. Enter the next number.
5. Press the equals (=) button.
6. View the calculated result.
7. Open the History screen to view previous calculations.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd Simple-Calculator
```

### 3. Open the Project

- Open Android Studio.
- Select Open.
- Choose the downloaded project folder.

### 4. Sync Gradle

Allow Android Studio to sync the project and required dependencies.

### 5. Run the Application

- Connect an Android device or start an emulator.
- Click the Run button in Android Studio.
- The Simple Calculator application will launch.
